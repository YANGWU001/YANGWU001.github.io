# Yang Wu

Personal academic site for Yang Wu, built with [Academic Pages](https://github.com/academicpages/academicpages.github.io) (MIT) and hosted at <https://yangwu001.github.io>.

Pages are generated from Markdown in `_pages`, `_publications`, `_talks`, `_teaching`, and `_portfolio`. Site-wide settings live in `_config.yml`. A PDF of the CV is in `files/Yang-Wu-CV.pdf`.
