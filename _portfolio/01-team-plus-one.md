Scientific discovery depends on timely input, but most AI assistants only react when asked, and real-time reasoning is often too slow to help in the moment.

This project builds a proactive LLM assistant that anticipates when to intervene and precomputes reasoning offline so collaborators in biomedical discovery can get help with low latency.

**Role:** Project lead, Worcester, MA, 2025 – present.
